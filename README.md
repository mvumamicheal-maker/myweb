\## Description

This repository contains a professional, responsive, and interactive student portfolio website developed as part of the ICT251 Web Technologies course. It showcases academic background, learning plans, projects, personal photo galleries, media recordings, and an interactive contact interface.



\## JavaScript Features Implemented

1\. \*\*Compulsory Contact Form Validation:\*\* Validates name, email, and message inputs upon submission, rejects whitespace-only values, displays inline feedback, and renders a secure local preview using `event.preventDefault()` and `textContent`.

2\. \*\*Mobile Navigation Toggle:\*\* Opens and closes the responsive menu on narrow screens via a burger button.

3\. \*\*Theme Switcher:\*\* Allows visitors to seamlessly toggle between light and dark visual themes.

4\. \*\*Project Search \& Filter:\*\* Enables visitors to filter projects/skills by category with an option to reset views.
